# 数据与素材存储

制作或修改应用、制作可安装模板时，先检查当前代码、绑定与构建产物，再决定数据库
和素材初始化。旧 metadata、来源应用的 localStorage 实现或已有截图不足以证明存储正确。

| 内容 | 正式应用的存放方式 |
| --- | --- |
| JavaScript、CSS、运行必需的代码依赖 | 随 Web 构建打包；CSS 可独立随包或内嵌 JS |
| 需要持久保存的记录、成绩、设置、文件业务关联 | Tiana 数据库；文件关联保存相对路径、名称及关联字段 |
| 随应用分发且单张不超过 16 KiB 的静态小图片 | 构建时内嵌 JS，复用同一份 data URL 或 SVG 字符串 |
| 其他需外置的图片、附件、音视频、字体、模型 | Tiana 文件存储，通过文件 API 访问 |
| 用户上传文件、需要长期保存的生成文件 | 不论大小，使用文件存储 |
| 尚未保存的输入、本局计算、短期缓存 | 可留在页面；缓存不能替代云端持久化 |

应用需要持久业务记录时接入 SQLite，不能把 localStorage、IndexedDB 或文件 BLOB
当作数据库，再据此声明 `database_required: false`。确实没有数据库持久化需求时
可无库，不为临时计算增加业务数据。数据库连接遵循当前 SQLite 技能的动态账号鉴权。

文件使用平台 `context.files`，详细调用见[文件存储](files.md)。数据库保存可重新解析
的应用相对路径，不保存二进制/base64 正文、作者 URL 或临时授权 URL。文件访问保留
当前租户与应用的授权范围，不能把文件存储当作跨租户匿名 CDN。

## 静态小图片的大小

- 单张上限为 16,384 字节，等于上限仍可内嵌，16,385 字节及以上使用文件存储。
- 测量缩放、压缩、格式优化后的实际文件，位于 base64/data URL 编码之前。
  SVG 测量优化后的完整 UTF-8 字节，不用像素数、原图或 HTTP 压缩后大小代替。
- 只适用于随应用分发的静态图片。用户上传图片和需长期保存的生成图片仍用文件存储。
- 检查干净构建中实际已进入 JS，不能只看 import，或把一张大图切碎来规避上限。

## 随包例外与预览

平台要求的根部 `icon.png` 按规范随包提供；不能据此把其他外置图片复制进 Web 包。
`showcase/preview.html` 保持自包含，使用合成示例和页面内状态，不访问作者或安装后
应用的正式数据库、文件。保留“示例体验／恢复示例”工具条，恢复仅重置本页示例。

临时绘制的 Canvas、图表或导出文件可以先在内存生成；用户需要长期保存时再写入
文件存储，不因此扩大应用功能。按实际接入描述数据库与文件的保存位置，尚未验证
的云端持久化不得写成已完成。

## 预置素材和验收

需外置的预置素材按[模板素材文件](template-files.md)进入当前安装的独立目录。
程序用 `template-assets/<相对路径>` 访问，数据库保留同一路径。仅作者应用能访问，
或仅源码中存在文件，都不足以证明新安装可用。

检查源码和构建、平台图标及自包含预览的例外；实际写入业务记录，刷新并在另一
授权会话读回。需要预置素材时核对新安装文件；有用户上传功能时另验证上传和原有
预览/下载操作。按实际功能验收，不为测试添加规格外的文件管理界面。
