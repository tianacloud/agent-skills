# 在 macOS WorkBuddy 使用 Tiana Cloud

WorkBuddy Connector 使用在线环境，并自动准备 Tiana CLI。安装、登录和更新说明见 [Connector 指南](workbuddy-connector.md)；通用 CLI 安装和开始使用见[开始使用](../skills/tiana/references/getting-started.md)。

在 WorkBuddy 中按客户端提供的方式安装或连接 Tiana Cloud，然后按浏览器提示登录并批准授权。密码和验证码只在产品页面输入，不要发送凭据或 Token。安装后开启新聊天，按需使用 Tiana Skills。手动导入 Skills 的方法见[项目说明](../README.md#从-npm-安装)。

如果命令不可用或登录失败，先查看客户端提示及 [Connector 指南](workbuddy-connector.md)中的配置说明；不要分享凭据文件。Windows 命令查找问题见 [Git helper 排查](../skills/tiana/references/windows-git-helper.md)。
